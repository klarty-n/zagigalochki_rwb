# Решения по качеству данных

Правила подтверждает пользователь после просмотра фактических ситуаций.
До подтверждения наблюдение не означает, что запись невалидна.
Исходные CSV и raw не исправляем и не удаляем.

| Код | Ситуация | Подтверждённое действие |
| --- | --- | --- |
| category_missing | У товара нет категории | Сохранить товар, категория NULL |
| category_translation_missing | Категория есть, английского перевода нет | Сохранить исходную категорию, перевод NULL |

Оба решения согласованы 28 октября 2026 года. Остальные ситуации ожидают решения.
Отклонение родительской записи и судьбу зависимых записей согласуем отдельно.
